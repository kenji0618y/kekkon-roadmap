# DECISIONS — 決めたこと・やめたこと（追記だけ）

**このファイルは消さない・書き換えない。下に足すだけ。**

数字は `npm run sync:docs` が自動で書き込むので、ここに書く必要はありません。
ここに書くのは、**機械では確かめられないこと**だけです。

## 何を書くか

画面から**何かを消したとき**、**何かを増やしたとき**、**方針を変えたとき**に、1行足してください。
そうしないと、次のAIが「これは古いから戻そう」と、消したものを復活させます。実際に起きました。

書き方（日付・何を・なぜ）:

```
- 2026-09-10 デスクの Amity 吹き出しを削除。右下のボタンと重複していたため。戻さない。
```

「戻さない」「これは残す」と書いてあるものは、**指示なく変えないでください。**
変える必要ができたら、古い行は消さずに、下に新しい行を足してください。
